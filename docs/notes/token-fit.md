# 토큰 핏: AI 크레딧을 꼭 필요한 만큼만 쓰기

2026-11-14 측정 · 담당 환희 · 코드: `lib/llm.ts`, `app/api/explain/route.ts`, `app/api/analyze/route.ts`

## 무엇을 찾았나

- 모델은 `claude-haiku-5-5`(안뇽GPT 게이트웨이, 100만 토큰당 입력 $0.1 · 출력 $0.5). 출력이 입력보다 5배 비싸다.
- Haiku 5.5는 **생각(thinking)이 기본으로 켜져 있다.** 화면에 안 보이는 생각 토큰이 출력으로 청구된다. 채점 1번에 보이는 답은 60토큰인데 출력은 348토큰이었다.
- OpenAI 방식 주소(`/chat/completions`)는 생각을 끄는 옵션을 무시했다. 게이트웨이의 Claude 전용 주소(`/claude/v1/messages`)에서는 `thinking: {type: "disabled"}`가 먹힌다.

## 전후 비교 (실제 호출로 잼)

| 일 | 전 | 후 | 정확도 |
|---|---|---|---|
| 말해보기 채점 1번 | 743토큰(입력 395 + 출력 348), 2.8초 | 약 325토큰(입력 285 + 출력 40), 평균 1.4초 | 4건 모두 맞음(바꿔 쓴 답 2, 틀린 답 1, 끼워 넣은 지시 1) |
| 분석 5명 | 6,641토큰(학생마다 1번), 15초 | 1,318토큰(5명 한 번에), 2.1초 | 5/5 → 5/5, 근거가 학생 글에 실제로 있음 5/5 |
| 분석 30명(위 숫자로 계산) | 약 4만 토큰, 약 $0.010 | 약 8천 토큰, 약 $0.0016 | 실제 30명 답으로 다시 확인 예정 |

채점 1번 비용은 약 $0.00021 → $0.00005(-77%), 30명 분석은 -83%.

## 바꾼 것

1. Claude 전용 주소로 바꾸고 생각을 끔. 답 길이 상한(`max_tokens`)을 정함(채점 200, 분석 1000).
2. 답 모양을 짧게: 채점은 `{"I1":"근거","I2":"근거","M2":false}`.
3. 분석은 5명씩 한 번에 묻는다. 학생 ID는 AI에 보내지 않고 번호만 쓴다.
4. 같은 질문은 3시간 동안 저장된 답으로 돌려준다(토큰 0). 저장 열쇠는 해시라 학생 글 원문이 열쇠로 남지 않는다.
5. 키워드로 결과가 정해지면 AI를 부르지 않는다. '크게' 같은 말이 보이면 AI가 뭐라 하든 M2 피드백이라 부르지 않는다.
6. 크레딧 보호: 하루 토큰 상한 `LLM_DAILY_TOKENS`(기본 10만), 비상 스위치 `LLM_DISABLED=1`, 학생 한 명당 AI 채점 10분에 5번.
7. 기다리는 시간: 다시 묻기까지 합쳐 채점 최대 6초, 분석 최대 12초. 잘린 답이나 거절은 다시 묻지 않는다(같은 결과에 토큰만 또 듦).
8. `/api/analyze`는 배포 주소에서 꺼 둔다(`ANALYZE_ENABLED=1`일 때만). 시연 전에 로컬에서 한 번 돌려 저장해 쓴다.
9. 서버 로그에 호출마다 숫자만 남긴다. 예: `[llm] explain 입력 285 · 출력 40 토큰 · 1361ms · 오늘 650/100000`. 학생 글과 키는 남기지 않는다.

## 주의

- 생각을 끌 수 없는 모델(예: Opus 5.5)로 `LLM_MODEL`을 바꾸면 400이 나서 대체 결과로 간다. 그 모델을 쓰려면 `lib/llm.ts`의 `thinking` 줄을 `output_config: {effort: "low"}`로 바꾸고 `max_tokens`를 늘린다.
- 초안 답 30개로 재 보니 생각 끔은 AI 26/30(7,801토큰), **effort low는 29/30(12,640토큰)**이었다(키워드만 20/30). 그래서 **분석만 effort low**를 쓴다(`app/api/analyze/route.ts`). 처음 방식(약 4만 토큰)보다 여전히 70% 적다. 실시간 채점(explain)은 생각 끔 그대로.
- 분석 몫은 하루 상한과 별도로 `LLM_ANALYZE_TOKENS`(기본 4만)까지만 쓴다. 분석을 여러 번 돌려도 학생 채점 몫이 남는다. 채점은 학생당 10분 5번 + 서버 전체 10분 40번.
- 진선우·김나희의 실제 30명 답과 독립 라벨이 오면 다시 돌려 `data/analysis.saved.json`을 새로 만든다.
- 토큰 수는 서버 메모리에서 센다. 서버를 다시 켜면 0부터 세고, Vercel은 인스턴스마다 따로 센다. 실제 도입 땐 DB·KV로 옮긴다.
