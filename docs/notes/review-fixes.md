# 총기획안 검토 결과 → 발표·PPT에 바로 고칠 것 (11/14 오전)

심사위원 4명 관점으로 냉정하게 채점한 결과 **69/100**. 아래를 고치면 80점 안팎을 기대할 수 있다는 판단이에요.
담당: 문제·근거 김나희 · 콘텐츠·고증 진선우 · 시연·AI 장면 정환희·신재우

## 1. 현장 문제 이해 (20점, 가장 많이 깎이는 곳) — 김나희
원인 3가지가 기능과 1:1이라 "기능에서 거꾸로 만든 원인"처럼 보여요. **두 개의 악순환**으로 다시 써요.
- 학생 고리: 선수 개념이 빠짐 → 영상이 이해 안 됨 → 끄거나 틀어만 둠 → 본시도 못 따라감 → 결손이 커짐
  (근거: 2025 학업성취도, 중3 국어 학습의욕 '높음' 3수준 이상 68.7% vs 1수준 45.3%)
- 교사 고리: 누가 어디서 막혔는지 모름 → 수업 시작에 모두에게 다시 설명 → 준비해 온 학생은 손해, 안 해 온 학생은 "안 봐도 된다"를 배움 → 사전학습이 더 줄어듦
  (근거: 플립러닝 연구 71편 리뷰에서 가장 많이 보고된 문제가 수업 전 준비 부족, Akçayır & Akçayır 2018, Computers & Education 126)
- 두 고리가 만나는 곳 = 수업 시작 5분(지도안의 전시 학습 확인). 징검다리는 여기를 끊는다.
- "지금 방법이 안 되는 이유" 4줄: 시청 시간 확인 → 틀어 놓고 딴짓 / 객관식 퀴즈 → 왜 틀렸는지 모름 / 서술형 → 담당 학생 전원 답을 매일 못 읽음 / 보상·상벌점 → 화면만 켜 둠(참여만 하면 주는 보상은 내재동기를 깎음, Deci 외 1999)
- "팀11"은 심사위원이 모르는 말 → "저희 팀 예비교사 두 명은 교생 실습과 학원에서 …봤습니다"

## 2. 시연에 "AI가 일하는 장면" 15초 넣기 — 정환희 대사, 신재우 화면
지금 시연에서는 AI가 한 번도 안 불려요(준비 문장은 키워드로 바로 통과). 수업 시작 직후, 함께 놓기 직전에:
- 화면: 예보 막힌 지점 1위 "ㄲ도 획을 더한 글자 ○명"을 누르면 학생 답 3개가 뜨고 AI가 짚은 근거 구절에 형광펜. 옆에 "키워드 규칙 1/3 · AI 3/3 · 선생님 확인 1"
- 대사: "표현이 다 달라서 키워드로는 하나만 잡힙니다. AI는 30명의 답을 읽고 근거 문장을 짚어 선생님께 보여 드립니다. 그래서 오늘 수업은 이 오개념에서 시작합니다."
- 답 3개는 키워드가 놓치고 AI가 잡는 실제 답에서 고른다(예: "ㄲ도 ㅋ처럼 ㄱ에서 하나 늘린 거라 만드는 법이 같다").
- 화면은 저장된 분석 결과로 그려서 와이파이와 무관하게.

## 3. AI 정확도 점검 방법 바꾸기 — 진선우·김나희
지금 방식(답 쓴 사람 = 라벨 단 사람)은 순환이라 AI 교수가 바로 짚어요.
1. 답은 진선우가 쓰고, 라벨은 김나희가 답만 보고 따로 붙인다(두 사람 일치도도 함께).
2. 쉬운 답 24개 + 어려운 답 6개(오개념 2개 섞임, 맞는데 표현이 엉뚱함, 맞춤법 많이 틀림, 한 낱말, 엉뚱한 말, "모르겠어요")
3. 같은 30개를 키워드 규칙만으로도 판정해 비교 → "오개념 판정 일치 N/30 (키워드만 M/30)"
4. 정직하게: "가상 답 30개로 한 점검이라 실제 정확도는 파일럿에서 다시 잽니다."

## 4. 교사가 매 차시 돌 세트를 만들어야 하나? — 답 추가
"새로 만드는 건 단원당 한 번, 쓰는 건 해마다입니다. 오개념은 해마다 거의 같아서 다른 반·다음 해·같은 교과 선생님과 함께 씁니다(교과협의회에서 단원 분담). 이번 소단원 세트는 예비교사 한 명이 약 ○시간(진선우 실측). 다음 단계는 지도안·성취기준을 넣으면 AI가 돌 카드·문항 초안을 만들고 선생님은 고치기만 합니다. 처음엔 선수 개념 없이는 안 되는 단원 한 학기 1~2개부터."

## 5. 기대효과에 기준선과 파일럿 설계 — 김나희
- 한 줄: "종이 울릴 때 선생님이 아는 것: 지금 0명 → 30명 전원의 도착 여부와 막힌 오개념 TOP 3"
- 8분: "함께 놓기는 지도안의 전시 학습 확인·도입 5~10분을 대신하는 것이고 8분은 상한. 잠긴 칸이 없으면 0분."
- 준비해 온 학생: 다시 설명 듣는 시간이 줄고 심화 돌·또래 튜터(희망자)
- 4주 파일럿: 같은 선생님 2개 반 비교, 1차 지표는 수업 전 도착률과 본시 형성평가(하위 30% 따로), 멈춤 기준(학생 하루 20분·교사 하루 10분 초과 시 설계 수정), 효과 없으면 없다고 보고
- Roschelle 문장은 범위대로: "메인주 43개교 중1 수학 2,850명 무작위 실험, 선수 성취가 낮은 학생이 가장 큰 혜택. 교과·형식이 달라 효과 크기는 파일럿에서 다시 잼."

## 6. 발표 시간과 팀원 기여도
- 목표 265초 + 여유 35초: 표지 5 · 문제 45(김나희) · 타겟 10 · 기능 35(진선우) · 시연 90(대사 진선우, 조작 신재우, AI 장면 15초 정환희) · 기대효과 65 · 마무리 15

## 7. 고증과 문구 — 진선우
- "세종이랑 같은 답" → 해례(제자해)는 정인지 등 집현전 학자가 쓴 부분이라 국어 심사위원이 짚을 수 있어요. **"580년 전 해례본과 같은 설명"**으로.
- 학생은 ㅌ을 설명했는데 원문 카드가 ㅋ比ㄱ 문장이라 어긋나요. 제자해의 "ㄴ而ㄷ ㄷ而ㅌ … 其因聲加畫之義皆同"(소리를 따라 획을 더한 뜻은 모두 같다)을 함께 보여 주세요(원문 확인 부탁).
- 키워드 판정 구멍: 생각2={세, 거세, 소리}면 "소리가 커서 획을 더했다"(세기=크기 오개념)도 통과, "세"는 "세종"에도 걸림 → 키워드를 "세게/세진/거세" 같은 어절로, "크게/커서"가 있으면 통과 안 되게.

## 10. 슈퍼스쿨 연동 문장 — 정환희
"영상 시청 기록을 슈퍼스쿨에서 받는다"는 공개 기능 설명에 없어요. 이렇게 말해요:
"새 데이터를 만들지 않고, 슈퍼스쿨 수업활동에 이미 있는 흐름에 붙입니다. 사전학습은 수업활동의 자료·설문·성찰로, 말해보기 미제출은 미제출 관리 그대로 참여 신호로, 아침 예보는 교사 홈 카드로. 붙이지 않는 것: 성장 마일리지(점수), 성적, 생기부. 영상 확인은 징검다리 플레이어가 확인 질문 응답만 남깁니다."
