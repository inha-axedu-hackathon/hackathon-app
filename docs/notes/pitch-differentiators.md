# 징검다리를 한 문장으로 · 다른 팀과 다른 점 (발표·PPT·Q&A용)

2026-11-14 · 정리 환희 · 화면은 지금 main 기준(교사 `/teacher`·`/teacher/approve`, 키오스크 `/checkin`, 학생 `/student/welcome`·`/student/river`, 교실·학생 홈은 재우)

## 1. 한 문장

- **긴 버전**: 수업 전에 반 전체의 '개념 말해보기'를 AI가 읽어 막힌 곳을 찾고, 학생마다 다른 개수의 징검돌로 메워서, 다리가 끊긴 곳에서 수업을 시작하게 하는 슈퍼스쿨 안의 교사 지원 서비스.
- **10초 버전**: "선생님은 종이 울린 뒤에야 압니다. 징검다리에서는 12분 전에 압니다."
- **각인 문장**: "다리가 끊긴 곳에서 수업이 시작된다" — 교사 화면 제목 옆에 그대로 있다.

## 3. 시연에 넣을 장면 후보 (대사는 진선우)

1. **교사 예보 15초(9-2의 43–58초)**: T → 헤드라인이 붉게 "병서 소나기 · 첫 8분은 함께 놓기", 아래 "함께 놓기 O/X: 'ㄲ도 획을 더한 글자다' — AI가 말해보기에서 찾은 8명의 오개념" → [함께 놓기 시작 · 8분 → 교실 화면]. 대사: "AI가 30명의 답을 읽었고, 규칙이 병서를 잠갔고, 시작은 선생님이 누릅니다."
2. **주요 기능 5초 · 아침 체크인**: `/checkin` QR → "15번 여울 맞나요?" → "오늘 돌 1개 · 1분이면 완주" → ㅇ O → 첨벙. 대사: "QR·바코드를 골라도 똑같습니다." (윤리 검토 권고: 시연은 QR로 해서 얼굴이 선택지일 뿐임을 보여 준다)
3. **주요 기능 5초 · 학생 정보 잠금**: `/teacher` [학생 정보 보기] → 얼굴 1초 → 원문·근거가 열리고 '내 열람 기록'에 남음. 대사: "학생 한 명 한 명이 드러나는 정보는 선생님이 다시 확인해야 열립니다."

시연 순서를 바꿀 때 주의: 키오스크에서 돌을 놓아도 N(다음 단계)은 옛이응의 ㅌ을 그대로 놓는다(store가 학생·돌까지 비교).

## 4. 예상 질문 답 (AI·데이터: 정환희)

- **"데이터가 이미 브라우저에 있지 않나요?"** → "지금 잠금은 화면에서만 가리는 시연용입니다. 실제 도입에서는 슈퍼패스 재인증을 서버가 확인한 뒤에만 학생별 정보를 10분짜리 열쇠로 내려 주고, 열람 기록은 학교 서버에 지울 수 없게 남깁니다."
- **"AI 비용은요?"** → "30명 분석 한 번에 약 1만 3천 토큰, 약 0.4센트입니다. 실시간 판정은 한 번에 약 340토큰이고, 같은 답은 다시 묻지 않습니다. 하루 상한과 비상 스위치도 있습니다."
- **"왜 가장 싼 모델인가요?"** → "짧은 분류 일이라 가장 싼 Claude Haiku로도 29/30이 나왔습니다. 그래야 학교 예산으로 매일 30명을 읽을 수 있습니다."
- **"AI가 틀리면요?"** → "근거 구절이 학생 글에 실제로 있어야 인정하고, 선생님이 TOP 3에서 판단을 뺄 수 있고, 관문은 실패하면 통과시키지 않고 '선생님이 확인할게요'로 갑니다."
- **"AI가 학생 의욕을 판단하나요?"** → "아니요. 8유형의 첫 축은 관찰한 참여 신호(제출·시도·SOS)이고 규칙이 계산합니다. 환경 걸림돌이 있으면 '낮아 보임'으로 두고 환경부터 풉니다(예비교사 설계, SPEC 8-1-1)."
- **"학생 동의는요?"** → "서비스와 얼굴을 따로 받고, 처음엔 둘 다 꺼져 있고, 동의마다 왜·무엇을·언제까지·안 하면을 알립니다. 만 14세 미만은 보호자 확인 뒤에 켜집니다."
